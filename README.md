# ITI Ruby Course

A beginner-friendly Ruby project created as part of the ITI Ruby Course. This repository demonstrates basic Ruby scripting, file handling, and simple inventory management.

## What’s included

- `main.rb` — the main application entry point
- `inventory.rb` — inventory-related logic for tracking and managing items
- `books.csv` — sample book dataset used by the application

## Project goals

- Learn how to read and write CSV data in Ruby
- Practice organizing Ruby code across multiple files
- Build a small command-line program that works with real data
- Develop a solid foundation for Ruby syntax, classes, and simple file operations

## How to run

1. Install Ruby if not already installed
2. Open a terminal in this project folder
3. Run:
   ```bash
   ruby main.rb
   ```

## Notes

This repository is designed for learners and includes a clean, minimal structure to help focus on Ruby fundamentals. Feel free to expand it with new features, improved data handling, or a user-friendly menu.
